# Week 02 — Exercise solutions (starter files)

This folder contains starter scripts for the Week 02 class exercise.

Files:
- `task1_regional_bar.py` — horizontal bar chart showing average happiness score by region.
- `task2_top_bottom_bar.py` — contrast chart showing top 8 and bottom 8 countries.

How to run:
1. From the `data-viz-class-material/week02/solutions` folder run:

```bash
python task1_regional_bar.py
python task2_top_bottom_bar.py
```

2. The scripts expect the dataset at `../data/world_happiness_2023.csv` (relative to this folder).

Notes:
- Each script uses Plotly and will open the chart in your browser or renderer.
- Customize titles, colours, and layout to meet the exercise requirements before pushing to your repo.
